# 03 — 兼容性矩阵

> 本矩阵只写**实际验证过**的内容。未验证的一律标 `NOT TESTED` /
> `未验证`，不声称可用。

## 1. 操作系统与架构

| 平台 | 架构 | 状态 | 说明 |
|---|---|---|---|
| Windows 11 (10.0.26100) | x64 | **已验证** | 本发行版的开发与验证平台 |
| Windows 10 | x64 | 未验证 | 理论上可用（依赖相同），但未实测 |
| Windows 11 | arm64 | 未验证 | Playwright Chromium 与 DSH 桌面端在 arm64 上未验证 |
| Linux | x64 | 未验证 | 脚本为 PowerShell；`-Action check` 会报 `NOT TESTED` |
| macOS | 任意 | 未验证 | 同上 |

`-Action check` 在非 Windows 平台会输出
`platform: NOT TESTED` 而不是 PASS。

## 2. DSH Desktop

| 项目 | 值 |
|---|---|
| 已验证版本 | **0.2.0-rc.2**（Electron 44.0.0） |
| 声明区间 | `>=0.2.0-rc.2 <0.3.0` |
| 同 0.2.x 的其他补丁版本 | 未验证（`check` 会报 `UNTESTED`，不阻止安装） |
| 0.3.x 及以上 | 未验证；`check` 会报 `UNTESTED`，安装前请先看发行说明 |

### 用到的 DSH 接口

| 包 | 用法 |
|---|---|
| `@deepseek-ai/dsh-agent-preset` | 声明 Preset（`id`/`name`/`description`/`order`/`plugins`） |
| `@deepseek-ai/dsh-mcp-client` | `serverName`、`transport: stdio`、`command`/`args`/`cwd`、`toolCallTimeoutMs`、`failOnStartupError`、`maxInstructionBytes`、`reconnect.*` |
| `@deepseek-ai/dsh-skill-filesystem` | `customSkillDirs` |
| `@deepseek-ai/dsh-tool-skill` | 技能工具 |
| `@deepseek-ai/dsh-plugin-manager` | `dsh plugin --profile <p> add/remove`（转发 pnpm） |
| Cordis loader `!!js` | entry config 的运行期求值（`interpolate`） |

任何一个接口变更都可能影响本发行版；升级 DSH Desktop 后请重跑
`tests\run_all.ps1`。

## 3. Python 与依赖

| 组件 | 要求 | 已验证 |
|---|---|---|
| Python | `>= 3.11` | 3.12.0（系统）、3.12.14（DSH 自带运行时） |
| uv | `>= 0.7.0` | 0.12.15 |
| cnki-mcp | `== 0.1.1`（固定） | 0.1.1 |
| mcp | `1.30.0`（由 `uv.lock` 固定） | 1.30.0 |
| playwright (Python) | `1.63.0`（由 `uv.lock` 固定） | 1.63.0 |
| Chromium（Playwright） | `chromium-1243` | 本机已存在并被复用 |

依赖解析完全由 `upstream/cnki-mcp/uv.lock` 决定；`uv sync --frozen` 不会重新解析
版本区间。**不复制**开发机上的 `.venv`。

## 5. 网络与外部依赖

| 阶段 | 需要网络 | 目标 |
|---|---|---|
| `-Action check` | 否 | — |
| 安装 Python 依赖 | 是（除非 uv 缓存已预热，可用 `-Offline`） | PyPI（`uv` 默认源） |
| 下载 Chromium | 是（若本机已存在 `chromium-1243` 则复用） | `playwright.azureedge.net` 等 Playwright CDN |
| `-Action install` 之后 | 否（相对于安装） | — |
| 检索时 | 是 | `cnki.net` / `fsso.cnki.net` |
| 模型调用 | 是 | DSH 自身配置的模型服务 |

**不需要** `http://127.0.0.1:7788`（上游的 HTTP 传输）。本发行版只用 stdio，
`tools/probe_mcp_stdio.py` 会验证这一点。

## 6. 路径字符兼容性

| 安装根目录形态 | 状态 | 验证方式 |
|---|---|---|
| 含空格（如 `D:\My Tools\CNKI Research`） | **已验证** | 静态测试 A7 用 `安装 目录`（空格 + 中文）做模拟布局求值 |
| 含中文（如 `D:\我的工具\知网`） | **已验证** | 同上 |
| 深层嵌套（> 200 字符） | 未验证 | Windows 长路径行为未实测 |
| UNC 路径（`\\server\share`） | 未验证 | 未实测 |
| 只读位置（如 `C:\Program Files`） | 不支持 | 安装器需要写入 `.venv`；请用 `-InstallRoot` 指向可写目录 |

本机实际验证时使用的安装根目录同时包含**空格**与中文，以覆盖最不利的路径形态；
对应的自动化断言是 `tests/test_static_package.mjs` 的 A7 组（求值 `!!js` 表达式）。

## 7. 与其他插件共存

| 场景 | 状态 |
|---|---|
| Profile 中已有其他 `@local/*` 或第三方 bundle | 未专门验证；安装器只增删自己的包名与 `dsh.profile.bundles` 条目 |
| Profile 中已装本插件（同名） | **已验证**：安装器拒绝静默覆盖，报告来源与版本 |
| 同一 DSH 有多个 Profile | 支持；安装器默认只动 `-DshProfile` 指定的那个 |
| 与 v1.1 `cnki-runtime` 共存 | **未验证，且不需要**；本发行版不依赖也不引入 v1.1 |

---

## 8. 已知不支持的场景

* 无 DSH Desktop 的纯 CLI 环境（本插件是 Preset，必须有宿主）。
* 无 Python 且无法安装 uv 的离线机器（可在有网机器上预热 uv 缓存后带 `-Offline`）。
* 需要**全文下载**的用途（上游不提供）。
* 需要无人值守的机构认证（必须人工在浏览器窗口完成）。
